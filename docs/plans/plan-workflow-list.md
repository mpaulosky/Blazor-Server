# Sandcastle Workflow

1. Get Open Labled Issue Review and create plan use Wayfinder skill rubber duck it
2. Implement plan with team including as needed
 [ ] a Architect
 [ ] a Backend Developer
 [ ] a UI Developer
 [ ] a Tester using TDD
 [ ] a scribe to document changes
3. Pre-Push
 [ ] Lint Markdown files if created or modified
 [ ] Lint Yaml/yml files if created or modified
 [ ] Buld and Test resolve issues until successfully completed
4. Commit and Push to GitHub
5. Create PR
6. Address GitHub Review PR Comments, Suggestions and Merge Conflicts
7. Merge PR and Document
