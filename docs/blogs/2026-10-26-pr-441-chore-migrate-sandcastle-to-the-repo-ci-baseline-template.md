# chore: Migrate Sandcastle to the repo-ci-baseline Template

- **Release tag:** `v0.0.182`
- **Source PR:** [#441](https://github.com/mpaulosky/Blazor-Server/pull/441)

## PR description

### Why

Blazor-Server's Sandcastle was the pipeline the Template was ported from, and it has fallen behind: the Template now carries the review before the push, the shared host-safety and gate modules, and Claude Review's structured output. The Template gained the opt-in UI developer role in mpaulosky/dotfiles#303, so this repo can migrate without losing it.

### What changed

- **Apply:** the Template's Owned files (`main.mts`, every `lib/` module but `repo-config.mts`, their tests, the review skill and agent, `scripts/review.sh`, workflows and hooks). 77 of the 83 changed files are byte-identical to `template/owned/`.
- **Per-repo values:** `.sandcastle/lib/repo-config.mts` carries this repo's role models (Opus 5.5 / Sonnet 5.5), the live `ui` entry, `MAX_ITERATIONS`, the pnpm hook, the six `dotnet-*` skills, `GATE_COVERED_CHECKS` (including each <code>Tests&#58; &#60;project&#62;</code> job), `CHECK_PATHS`, `REPO_SLUG` and `NOT_OWNED_BASELINE_PATHS`.
- **Gate:** `.github/ci/gate-checks.sh` runs the Sandcastle check through `.sandcastle/check.sh`, whose path list also covers the review files, the workflows, `tests/` projects and the files `repo-config.test.mts` reads.
- **Tests:** `main.test.mts` now tests the Template's `main.mts` wiring; new `lib/repo-config.test.mts` pins `GATE_COVERED_CHECKS` to `ci.yml` and `tests/` and `CHECK_PATHS` to real files; `role-prompts.test.mts` also checks `plan-prompt.md` asks for a `files` list.
- **Docs:** `CODING_STANDARDS.md` points to `docs/CODING_STANDARDS.md`; the plan, `.claude/rules/` and `CLAUDE.md` describe `repo-config.mts`, the Owned/Seed split and the `review:claude` label as they are.
- **Kept:** `sandcastle.yml` and `copilot-review-sync.yml` (Sandcastle's own, not the Template's), the role prompts, `Dockerfile` and `package.json`. `.claude/settings.json` stays absent (PR #184).

### Verification

- `scripts/gate.sh` passes, including the build and every test project; `pnpm run check:sandcastle` passes (1995 tests).
- A read-only comparison of the old and new overlap/critique wiring found the Template equivalent, with no missing behaviour. One effect: each issue currently held under the old overlap comment marker gets one new comment on the first run.
- Local `/pre-push-review`: 3 rounds, 15 findings. 4 Critical, 1 Warning and 8 Advisory fixed; two Advisory left in #440.
- Not verified: whether the integration tests start containers in the Sandcastle sandbox, which has no Docker daemon. `GATE_COMMAND` is `scripts/gate.sh`, as the old pipeline ran it; if they fail red there, point it at `.sandcastle/check.sh`.
