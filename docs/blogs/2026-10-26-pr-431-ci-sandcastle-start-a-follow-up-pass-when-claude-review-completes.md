# ci(sandcastle): Start a follow-up pass when Claude Review completes

- **Release tag:** `v0.0.181`
- **Source PR:** [#431](https://github.com/mpaulosky/Blazor-Server/pull/431)

## PR description

### Why

Sandcastle's follow-up pass answers and resolves bot review threads, the Claude review's included. But a Claude review didn't start a pass:
- **No review trigger:** Claude Review posts with `GITHUB_TOKEN`, and GitHub starts no workflow from an event made with that token, so `sandcastle.yml`'s `pull_request_review` trigger never fires for it.
- **No CI trigger either:** the review usually lands after **Build and Test Suite** has finished, so the `workflow_run` trigger has already gone by.

A Claude review's threads therefore waited up to two hours for the scheduled run. mpaulosky/auth0-management-app#44 hit this. The same fix is in mpaulosky/auth0-management-app#46 and mpaulosky/dotfiles#259.

### What changed

- `.github/workflows/sandcastle.yml`: the `workflow_run` trigger follows **Claude Review** as well as **Build and Test Suite**, as PR Auto-Merge already does.
  - Claude Review runs on `pull_request`, so its `workflow_run` event carries the PR's branch and repository. The job's existing condition (same repository, a `feature/`, `fix/` or `hotfix/` branch) applies to it unchanged.
- `docs/plans/sandcastle-workflow.md`: the trigger list and the sweep paragraph name the new trigger and say why it's needed.
- `.claude/rules/baseline.md`: it listed every workflow as Owned by the Template. It now names `sandcastle.yml` as this repository's own, so a change to it is made here rather than sent to the Template.

`sandcastle.yml` isn't a repo-ci-baseline Template file (the Template's `references/tokens.md` calls it "dotfiles' own (and Blazor-Server's), not a Template workflow"), so a re-Apply won't overwrite this change.

### Verification

- actionlint, yamllint and zizmor pass on `sandcastle.yml`, and markdownlint passes on both Markdown files.
- The pre-push gate passed.
- The live check comes after merge: the next Claude review on a Sandcastle PR should start a Sandcastle run (event `workflow_run`) that isn't skipped.
